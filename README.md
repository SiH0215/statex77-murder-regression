# R을 활용한 미국 50개 주 살인율 다중회귀분석

R 내장 데이터 `state.x77`을 활용하여 주별 살인율과 관련 변수의 관계를 탐색하고, 변수 선택과 회귀 진단을 거쳐 다중회귀모형을 구성한 개인 학습 프로젝트이다. 2021년에 작성한 발표자료와 분석 기록을 보관한다.

## 데이터와 분석 내용

- 데이터: R `datasets` 패키지의 `state.x77` — 미국 50개 주, 8개 변수
- 종속변수: `Murder` — 인구 10만 명당 살인 및 과실치사율
- 검토한 설명변수: `Population`, `Income`, `Illiteracy`, `Life Exp`, `HS Grad`, `Frost`, `Area`

분포와 요약 통계, 변수 간 상관관계를 살펴본 뒤 `lm()`으로 모형을 구성하였다. VIF로 다중공선성을 검토하고, 변수 제거 및 전진·후진·단계적 선택 결과와 AIC·수정결정계수를 비교하였다. 이후 이상치와 잔차를 검토하고, 최종 모형의 실제값과 적합값 차이를 정리하였다.

발표자료의 최종 모형은 Nevada를 제외한 49개 주를 대상으로, 절편 없이 `Illiteracy`와 `Population`을 사용한다.

```r
lm(Murder ~ 0 + Illiteracy + Population, data = analysis_data)
```



## 실행 방법

R을 설치한 뒤 저장소 최상위 폴더에서 실행한다. 최종 모형 적합과 기본 진단 그래프 출력에는 R 기본 패키지만 필요하다.

```sh
Rscript reproduce_final_model.R
```

실행하면 `results/`에 모형 요약, 실제값·적합값·잔차 CSV, 진단 그래프 PDF가 생성된다. VIF·등분산성·Durbin-Watson 검정까지 출력하려면 다음 패키지를 설치한 뒤 다시 실행한다.

```r
install.packages(c("car", "lmtest"))
```

원본 `statex77_regression.R`은 RStudio에서 UTF-8로 열어 분석 단위별로 확인하는 학습 기록이다. 중간 객체명과 PC별 `setwd()` 경로가 포함되어 있으므로 일괄 실행용으로 제공하지 않는다. 원본에서 참조한 패키지는 `car`, `corrplot`, `dplyr`, `ggplot2`, `gmodels`, `lmtest`, `magrittr`, `MASS`, `pastecs`, `psych`, `readxl`, `reshape`, `skimr`, `tibble`, `tidyverse`이다.



## 결과 해석

- 발표자료의 수정결정계수는 분류 정확도가 아니다. 절편 없는 모형의 비중심 결정계수이므로 절편을 포함한 모형의 결정계수와 단순 비교하지 않는다.
- 발표자료의 AIC 81.19는 `step()`·`extractAIC()`에서 사용하는 기준이다. `AIC()` 출력값은 상수항 처리 차이로 다른 값이 나온다.
- 실제값과 적합값 비교는 모형에 사용한 자료에 대한 비교이다. 별도 테스트 데이터에서 검증한 예측 성능을 의미하지 않는다.
- 원본의 단위 표기와 일부 검정 해석에는 학습 당시의 오기가 남아 있다. `Murder` 값은 백분율이 아니며, “0 > 0.05”와 같은 표기는 올바른 검정 해석이 아니다. 검정 결과는 실제 출력값을 기준으로 확인해야 한다.
- 주별 집계 자료를 이용한 학습 분석이며, 변수 간 관계를 개인 수준의 인과관계로 해석하지 않는다.
